# CosmoForge Space Environment Pack

Generated by `cosmoforge_space_environment_pack.py` using Blender 5.x. The
generator uses no external textures or downloads.

## Files

- `cosmoforge_space_environment_pack.blend` — editable source and previews.
- `cosmoforge_space_environment_pack.glb` — every reusable environment asset.
- `space_environment_individual/` — Earth, Moon, Mars, Venus, asteroid set,
  space FX, orbit UI and Sun as separate GLBs.

## Asset structure

The transform roots are `Planet_Earth`, `Planet_Moon`, `Planet_Mars`,
`Planet_Venus`, `Star_Sun`, `AsteroidField_Demo`, `CF_Starfield` and the named
space/UI effect roots. Move, scale or hide a root together with its children.

Earth contains independently rotatable `Earth_Clouds` and hideable
`Earth_Atmosphere`. Venus contains `Venus_CloudLayer_01`,
`Venus_CloudLayer_02` and `Venus_Atmosphere`; give the cloud roots slow,
different rotations to avoid an obviously repeating surface.

The six named asteroid source meshes are intended for instancing. Objects below
`AsteroidField_Demo` share those mesh datablocks inside Blender. In a game,
instance a small selection at varied transforms rather than cloning unique mesh
data.

`Scene_LEO` through `Scene_Cursed` are configuration empties with custom
properties describing their focus asset, light preset and mood. They do not
duplicate environment geometry.

Main reusable object names:

- Earth: `Planet_Earth`, `Earth_Surface`, `Earth_Clouds`,
  `Earth_Atmosphere` and six `Earth_Land_*` / four `Earth_CloudBand_*` pieces.
- Moon: `Planet_Moon`, `Moon_Surface`, six `Moon_Crater_*` pieces and
  `Moon_CraterForeground`.
- Mars: `Planet_Mars`, `Mars_Surface`, `Mars_Canyon`, `Mars_PolarCap`,
  `Mars_Rock_A`, `Mars_Rock_B`, `Mars_Ridge` and `Mars_DustCloud`.
- Venus: `Planet_Venus`, `Venus_Surface`, `Venus_CloudLayer_01`,
  `Venus_CloudLayer_02`, their fourteen cloud bands and `Venus_Atmosphere`.
- Asteroids: `Asteroid_A` through `Asteroid_E`,
  `Asteroid_Fragment_Small` and the 38 shared-mesh children of
  `AsteroidField_Demo`.
- Deep space: `CF_Starfield`, `Space_Nebula_Volume`, `Space_DistantDust`,
  `Space_UnknownGlow`, `Space_CursedDistortion` and `Space_ImpossibleStar`.
- Solar/UI: `Star_Sun`, `Orbit_Path`, `Mission_TargetMarker`, `Signal_Ping`,
  `Navigation_Beacon` and `Unknown_SignalMarker`.
- Cameras: `Camera_WideMission`, `Camera_ProbeHero`,
  `Camera_PlanetApproach`, `Camera_Orbit`, `Camera_StrangeEncounter`.
- Lights: `Light_CoolKey`, `Light_MarsBounce`, `Light_VenusAmber`,
  `Light_DeepSpaceRim`, `Light_CursedAccent`.

The generator prints every generated object, including numbered star, dust,
crater, cloud and asteroid-instance children, after exporting.

## Mobile / performance mode

Objects carrying the `cf_optional_mobile` custom property may be hidden first:

- `Earth_Atmosphere`
- `Venus_Atmosphere`
- both Venus cloud-layer roots if necessary
- `Mars_DustCloud`
- `Space_Nebula_Volume`
- `Space_DistantDust`
- `Space_UnknownGlow`
- `Space_CursedDistortion`
- `CF_Starfield` (replace with a smaller game-native star field if desired)
- `AsteroidField_Demo` (instance fewer source asteroids instead)
- `Sun_Corona`

Planet surfaces, foreground rocks, asteroid sources and mission markers are
cheap enough to retain. Transparency and many tiny stars generally cost more
than the chunky planet geometry.

## Runtime toggling

In Three.js, locate a root with `scene.getObjectByName(name)` and set its
`visible` property. Rotate cloud roots directly. Reuse the same loaded asteroid
geometry/material with `THREE.InstancedMesh` for large fields.

The cursed ring is intentionally an optional accent. Keep it absent during
ordinary missions. `Space_ImpossibleStar` is designed to remain almost normal:
its thin secondary ring is the only visual warning that the count may now be
2,844.

## Rebuilding

From this directory:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python cosmoforge_space_environment_pack.py
```

Pass `-- --output-dir C:\somewhere` to use a different output directory.
